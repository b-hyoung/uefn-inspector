# TIMEBOX — 레벨 1개 = 3시간 예산

> 시간 개념이 없으면 한 레벨에 하루가 간다. 레벨(Task) 하나를 **3시간**에 끝내기 위한 배분·규칙.

## 배분 (레벨 1개 = Task 1개)
| 구간 | 티켓 | 예산 | 산출 |
|---|---|---|---|
| 1 | 레벨 뼈대 (공간·배치) | **40분** | 구조검증 통과 |
| 2 | 메카닉 배선 (Verse+@editable) | **40분** | 미배선 0 · 설정=변주조건 |
| 3 | 측정 로그 심기 | **30분** | 지표 전부 로그 출력 |
| 4 | 자동 실행 & 집계 | **30분** | metrics.md 채워짐 |
| 5 | 적대적 리뷰(빠른×4 + 전면×1) | **20분** | 판단가능성 판정 |
| — | 예비(초과 흡수) | **20분** | — |
| | **합계** | **180분** | |

## 초과 규칙 (구간별 예산 초과 시)
1. **1차 초과(≤25%)** — 계속하되 `state/session-log.md`에 원인 기록
2. **2차 초과(>25%)** — **스코프 컷**: 이번 레벨에서 뺄 것을 정하고 진행
   (우선순위: 측정 로그 > 배선 > 공간 디테일 — **측정은 절대 못 뺀다**, 빼면 판단 불가)
3. **구간 3·4 초과** — 즉시 **정지게이트**. 측정이 안 되면 이 레벨은 무효라 시간만 태운다.

## 시간 먹는 함정 (미리 아는 것들)
- **GUI 전용 @editable 배선** → 사람 대기. 발견 즉시 정지게이트, 다른 티켓으로 우회
- **자동 구동 모드 부재** → 구간 4에서 폭발. **레벨 A(대조군)에서 한 번 만들어 재사용**
- Verse 컴파일 에러 반복 → 3회 실패 시 정지게이트
- 에디터 열고 닫기 반복 → 오프라인 작업(1·2 일부)을 **닫힌 채 몰아서**

## 레벨 4개 전체 (1세트)
- A(대조군)는 **자동 구동 모드 구축** 때문에 **+1시간** 예상 (총 4h)
- B·C·D는 A를 복제·변주하므로 **각 2h 이하** 목표
- 1세트 총 ~10시간 → 실험 결론까지 **약 이틀 작업**
