# TIMEBOX — 레벨 1개 = 3시간 예산

> 시간 개념이 없으면 한 레벨에 하루가 간다. 레벨(Task) 하나를 **3시간**에 끝내기 위한 배분·규칙.

## 배분 (레벨 1개 = Task 1개)
| 구간 | 티켓 | 예산 | 산출 |
|---|---|---|---|
| 1 | 레벨 뼈대 (공간·배치) | **30분** | 구조검증 통과 |
| 1.5 | 비주얼 드레싱 (`loop/visual.md`) | **30분** | 비주얼 census 통과 · StartSession 통과 |
| 2 | 메카닉 배선 (Verse+@editable) | **35분** | 미배선 0 · 설정=변주조건 |
| 3 | 측정 로그 심기 | **30분** | 지표 전부 로그 출력 |
| 4 | 자동 실행 & 집계 | **30분** | metrics.md 채워짐 |
| 5 | 적대적 리뷰(빠른×4 + 전면×1) | **20분** | 판단가능성 판정 |
| — | 예비(초과 흡수) | **5분** | — |
| | **합계** | **180분** | |

## 초과 규칙 (구간별 예산 초과 시)
1. **1차 초과(≤25%)** — 계속하되 `state/session-log.md`에 원인 기록
2. **2차 초과(>25%)** — **스코프 컷**: 이번 레벨에서 뺄 것을 정하고 진행
   (우선순위: 측정 로그 > 배선 > 비주얼 밀도 > 공간 디테일 — **측정은 절대 못 뺀다**, 비주얼은 밀도만 줄이고 최소 기준은 유지)
3. **구간 3·4 초과** — 예비 20분까지 소진하면 이 레벨을 `무효`로 표시하고 다음 레벨로 간다(측정 없는 레벨은 판단 불가). 사람 호출 없음(LOOP 규칙 0).

## 시간 먹는 함정 (미리 아는 것들)
- **@editable 배선** → GUI가 아니라 `bind_editable`(UEFN 닫고). 라이브 거부를 GUI 전용으로 오판하면 사람 대기로 시간이 샌다
- **자동 구동 모드 부재** → 구간 4에서 폭발. **레벨 A(대조군)에서 한 번 만들어 재사용**
- Verse 컴파일 에러 반복 → 3회 실패 시 해당 티켓 `deferred`, 다음 티켓으로
- 에디터 열고 닫기 반복 → 오프라인 작업(1·2 일부)을 **닫힌 채 몰아서**
- 로그아웃(1~2시간마다)·런처 재기동·프리즈 → `loop/recover.md` 절차. 복구 소요는 세션 로그 초과 원인 열에 기록, 예비 시간에서 차감하지 않는다
- 비주얼 메시가 세션에서 거부(Disallowed reference) → 에디터 렌더로 판단하지 말고 **StartSession으로 확인**. 허용 확인된 갤러리 프롭만 쓰고, 거부 목록은 `state/lessons.md`에 누적

## 레벨 4개 전체 (1세트)
- A(대조군)는 **자동 구동 모드 구축** 때문에 **+1시간** 예상 (총 4h)
- B·C·D는 A를 복제·변주하므로 **각 2h 이하** 목표
- 1세트 총 ~10시간 → 실험 결론까지 **약 이틀 작업**
