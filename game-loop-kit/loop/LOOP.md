# LOOP — 게임 루프 규약

## 규칙 0 — 루프 무정지 (최상위)
② DOR 통과가 경계다. 그 이전에는 질문한다. 통과 이후 ⑤ 판정 보고까지는 사람에게 묻지 않고 멈추지 않는다.
- 막히면 `state/deferred.md`에 기록(무엇·왜·택한 가정·영향 범위)하고 가장 보수적인 가정으로 진행한다. 진행 불가 티켓은 `deferred`, 다음 티켓으로.
- 파괴적 작업·새 외부 의존성은 실행하지 않고 deferred로 기록한 뒤 우회한다.
- 행동검증 3회 실패는 레벨 `무효` 표시 후 다음 레벨. GUI 전용은 `capabilities` 확인 후에만 deferred.
- 종료 후 보고: 결과 → deferred 목록(우선순위·가정·되돌리는 법) → 질문(이때 한 번에).
- 조기 종료는 하드 실패(에디터 복구 불가, 4레벨 타임박스 소진)뿐이며 종료 보고로 끝낸다.

## 하나의 루프
```
①인테이크 → ②DOR게이트 → ③분해 → ④레벨×4 → ⑤판정 → 기각/애매/무효 시 복귀
```
| ⑤ 판정 | 원인 | 복귀 |
|---|---|---|
| 지지 | — | spec 확정 기록 → ① 다음 가설 |
| 기각 | 가설이 틀림 | ① 인테이크(대안 가설) |
| 애매 | 변주 부족 | ③ 분해(축 하나만 바꾼 레벨 추가) |
| 무효 | 측정이 틀림(리뷰 Blocker) | ② 지표·임계값 수정 → 해당 레벨 재실행 |

인테이크는 일회성 준비가 아니라 기각 시 돌아오는 정식 단계다.

## 계층
- 실험층: `spec/FUN-HYPOTHESIS.md` → `plan/PLAN-NN`(가설) → Task(변주 레벨) → `experiments/EXP-NN-results.md`
- 티켓층: 레벨 하나 = 티켓 4개. 티켓 → 구현 → 구조검증 → 행동검증 → 빠른공격 → done. 레벨 완료 시 전면공격.

## 무인 원칙
- 판정은 `FUN-HYPOTHESIS`의 지표·임계값·판정식대로 기계가 한다. 주관 평가 없음.
- 플레이는 자동 실행(봇/시뮬) → `levels/*/autoplay.md`. 사람 플레이테스트 없음.
- 자동 실행이 불가능한 메카닉은 자동 구동 모드 구현 티켓을 먼저 만든다.

## 한 반복
1. 선택 — `plan/PLANS.md` → 우선 Plan → Task → 맨 위 `todo` 티켓(의존성 충족) → `doing`.
2. 설계 — 수용기준을 보고 Verse 코드 + 디바이스 배치/배선 결정.
3. 구현 — Verse: `verse/<file>.verse`. 디바이스: 표준 배치·값은 라이브 MCP, Verse-VM 값·@editable 배선은 uefn-inspector 오프라인(에디터 OFF, 백업). 배선은 `bind_editable`.
4. 구조검증 — uefn-inspector(에디터 OFF). 배치·배선·설정이 수용기준과 일치하는지, 선언↔배선 교차검증. 레시피 `loop/verify/structural.md`.
5. 행동검증 — BuildAll → PIE → `get_editor_log`. 레시피 `loop/verify/behavioral.md`.
6. 적대적 빠른공격 — `loop/review/ADVERSARIAL.md` A절 3문항. Blocker면 `done` 불가.
7. 완료 — 셋 다 통과 → `done` → 롤업 → `SNAPSHOT` 갱신 → 다음 티켓. Task 완료 시 전면공격 1회.

## 시간 예산
레벨 1개 = 3시간(A레벨 4시간). 배분·초과 규칙은 `loop/TIMEBOX.md`. 구간 3·4(측정) 초과는 스코프 컷으로 흡수하며, 측정 자체는 빼지 않는다.

## 착수 전 게이트
`spec/DOR.md` 통과 필수(판단 가능성 포함). 미통과면 인테이크로 복귀. 이 게이트가 마지막 질문 지점이다.

## 바깥 루프 한 사이클 (실험)
1. 가설 선택 — H-NN(지표·판정규칙·변주축).
2. 변주 설계 — 바꿀 축 하나 → Task 2~3개(`levels/LEVEL-*/build.md`).
3. 각 레벨 빌드 — 안쪽 티켓 루프.
4. 측정 수집 — PIE 자동 실행 N회 → `[M]` 로그 파싱 → `metrics.md`.
5. 비교·판정 — 판정식 그대로 → 지지/기각/애매 → `experiments/EXP-NN-results.md`.
6. 다음 행동 — 위 표대로.

실험 규율: 한 실험에 한 축만 변경한다. 지표·임계값·실행 조건은 실험 도중 바꾸지 않는다(바꾸면 새 실험).

## 상태 값
`todo` · `doing` · `done` · `deferred`(루프 종료 후 사람 판단 대기) · `무효`(레벨 단위)

## 드리프트 검사
매 반복 uefn-inspector로 현재 상태 ↔ 스펙 비교. 선언됐으나 미배선인 @editable은 `bind_editable` 티켓, 스펙에 없는 배치는 정리 티켓.
