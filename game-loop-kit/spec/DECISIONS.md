# DECISIONS — 결정 카드 로그 (ADR)

기획 루프에서 사용자에게 간 결정과 그 답을 전부 적는다. 미결 카드가 0개여야 DOR로 간다. 형식은 `mattpocock-skills:domain-modeling`의 ADR과 같게 두어 용어집(`CONTEXT.md`)과 함께 관리한다.

## 카드 형식
```
## D-NN · <제목> · R<라운드> · 상태 [미결|확정|철회]
- 질문: <한 문장>
- 선택지: A <…> / B <…> / C <…>
- 추천: <A|B|C> — <이유 한 줄>
- 트레이드오프: A는 <얻는 것/잃는 것> · B는 …
- 바꾸는 문서: <GDD §n · systems/x · MAP §구역표 · FUN-HYPOTHESIS H-nn>
- 답: <사용자 선택> (<날짜>) · 근거: <사용자 말 그대로 한 줄>
- 파급: <이 결정으로 다시 열린 질문 D-MM>
```

## 규율
- 카드 하나 = 결정 하나. 사실 확인은 카드가 아니다(AI가 찾는다).
- 추천 없는 카드는 내지 않는다. 사용자가 추천을 뒤집으면 근거를 그대로 적는다.
- 확정 카드를 바꾸려면 새 카드로 철회를 기록한다. 덮어쓰지 않는다.
- 뻔한 기본값은 카드가 아니라 통보다. 통보 목록은 이 파일 끝 "기본값으로 정한 것"에 한 줄씩 적어 사용자가 언제든 뒤집을 수 있게 한다.
