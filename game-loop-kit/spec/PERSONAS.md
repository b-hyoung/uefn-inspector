# PERSONAS — 종이 플레이스루용 플레이어 대리인

용도: 기획 루프 R5에서 AI가 플로우 표 위에서 판을 굴려 빌드 전에 구멍을 찾는다. 페르소나는 행동 규칙이 다른 대리인이며, 사람 플레이의 대체가 아니라 **설계 구멍 탐지기**다. 결과는 `spec/playtests/PAPER-NN.md`.

## 페르소나 5종
| 이름 | 행동 규칙 | 잘 찾는 구멍 |
|---|---|---|
| 초보 | 처음 보는 것에 다가간다. 표지판·소리·빛을 그대로 따른다. 규칙을 모르면 가장 눈에 띄는 것을 한다 | 가독성 부족 · 첫 결정까지 너무 긺 · 설명 없는 규칙 |
| 숙련 | 최단 경로·최적 수단만 쓴다. 한 번 통한 전략을 반복한다 | 지배 전략 · 심층(숙련)이 비었는지 · 역전 부재 |
| 캠퍼 | 안전지대·시야 좋은 곳에서 기다린다. 위험을 감수하지 않는다 | 안전지대 대가 없음 · 대기 시간 공백 · 타이머 압박 부재 |
| 트롤 | 규칙을 만족시키면서 재미없게 놀 방법을 찾는다. 지표를 올리되 게임을 망친다 | 굿하트 오염 · 없는 규칙(동점·이탈·동시 발생) · 스폰 킬·병목 악용 |
| 협동가 | 남을 돕고 정보를 나눈다. 혼자 다 할 수 있으면 협동을 안 한다 | 상호의존 부재 · 소통 필요 없음 · 무임승차 |

## 플레이스루 형식 (한 판)
```
# PAPER-NN · 페르소나 <이름> · 역할 <역할> · 상대 <페르소나/역할> · 레벨 원형 MAP.md
| t | 자리 | 아는 것 | 결정(선택지 → 택한 것, 페르소나 규칙 근거) | 발동 규칙 | 상대 상태 | 결과 |
...
## 발견
- [지배전략|병목|재미공백|규칙구멍|정보문제|가독성|대기공백] <무엇> — 어느 줄(t)에서 · 왜 — 처리: [스펙 수정|맵 수정|결정 카드 D-NN|빌드 필요]
```
결정은 페르소나 규칙에서 기계적으로 도출한다. "재미있을 것 같다"는 쓰지 않는다. 결정 근거가 없는 줄은 그 자체가 발견(결정 없는 구간)이다.

## 판 구성 (최소 15판)
- 페르소나 5종 × 역할별 3판. 역할이 둘이면(술래/도망자) 상대도 페르소나를 바꿔 짝을 섞는다.
- 3판 중 1판은 규칙 하나를 극단값(변주 범위의 끝)으로 두고 돈다. 수치 표의 범위가 맞는지 본다.
- 멀티 판은 다인 플로우 표(`flow.md` §2) 위에서 t를 맞춰 굴린다. 만남 줄에서 양쪽 결정을 모두 적는다.

## 발견 처리
| 분류 | 기본 처리 | 어디로 |
|---|---|---|
| 지배 전략 | 약점 규칙 또는 대안 수단 추가 | R3 |
| 병목 | 합류점 분산 또는 의도 명시 | R4 |
| 재미 공백 | 그 줄에 결정 또는 만남 추가 | R4·R5 |
| 규칙 구멍 | 경계값·동시 발생·이탈 규칙 추가 | R3 |
| 정보 문제 | 표지·소리·빛으로 알림 추가 또는 비대칭을 의도로 확정 | R4 |
| 가독성 | 랜드마크·색 규칙 | R4(맵)·비주얼 의도 |
| 대기 공백 | 관전·재진입·역할 전환 규칙 | R3 |
| 빌드 필요 | 종이로 판단 불가(손맛·타이밍·AI 반응) → `state/uncertainty.md` 빌드 목록 | 실험 가설 |

## 한계 (정직히)
종이 플레이는 타이밍·손맛·AI 가드의 실제 반응·네트워크를 모른다. 이런 발견은 결론이 아니라 빌드 필요 항목이다. 종이에서 문제가 없다는 것은 "빌드 전에 알 수 있는 문제가 없다"는 뜻일 뿐이다.
