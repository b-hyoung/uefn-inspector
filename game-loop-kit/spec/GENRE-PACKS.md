# GENRE-PACKS — 장르별로 반드시 잡아야 할 디테일

> **왜:** 같은 "재미 파기"라도 장르마다 **결정적 변수**가 다르다. 슈터의 TTK, 퍼즐의 난이도 곡선,
> 레이싱의 코너 밸런스는 서로 대체되지 않는다. 이 문서는 **INTAKE에서 어떤 추가 질문을 던질지**의 분기표다.
>
> ⚠️ **원칙(하네스 규칙 준수):** 장르는 **답이 아니라 질문의 안내자**다.
> "슈터니까 TTK는 보통 X초"처럼 **관습을 값으로 가정하지 않는다.** 값은 이 게임의 설계·측정에서 나온다.
> 여기 적힌 수치·범위는 전부 **예시(illustrative)** 이며 사용자 확정이 필요하다.

## 사용법
1. INTAKE Phase 2에서 컨셉이 나오면 → 아래에서 **가장 가까운 팩 1~2개** 선택 (하이브리드면 둘 다)
2. 그 팩의 **필수 질문**을 Phase 3.5(깊이 파기) 뒤에 이어서 던진다
3. 답 → `systems/`의 규칙·공식, `FUN-HYPOTHESIS`의 지표, 4레벨 **변주 축**으로 흘려보낸다
4. 팩에 없는 장르면 → 가장 가까운 팩 + **공통 질문**으로 시작하고, 새 팩을 이 문서에 추가

---

## 공통 (모든 장르 — 팩 질문 전에)
- **Core Verb** 1개 / 승패·종료 조건 / 세션 길이 / 실패 시 무엇을 잃나(재시작 비용)
- **인원수 구조:** 솔로 / 협동 / 대전(1v1·NvN) / 비대칭 — *4레벨 변주의 인원 축*
- **정보 구조:** 완전정보 vs 불완전정보 (누가 무엇을 아나) — 대부분 재미의 뿌리

---

## PACK-A · 전투/슈터 (Combat / Shooter)
**결정적 디테일**
- **TTK**(적을 제거하는 데 걸리는 시간) — 짧으면 기습·정보 중심, 길면 조작·포지셔닝 중심
- **교전 거리 분포** — 근/중/원 어디서 대부분 싸우나 (맵 구조와 직결)
- **정보 획득 수단** — 시야·소리·미니맵·흔적 중 무엇으로 적을 아나
- **비대칭성** — 무기·클래스 간 우열이 아니라 **역할 차이**인가
- **재진입 규칙** — 리스폰/부활/관전 (세션 리듬 결정)

**필수 질문**
1. 적을 제거하는 데 몇 번의 성공적 행동이 필요한가? (TTK를 **횟수**로 먼저)
2. 플레이어는 적의 위치를 **어떻게** 아나? 모르면 무엇을 하나?
3. 죽으면 무엇을 잃고 언제 돌아오나?
4. 두 플레이어가 다른 선택(무기/클래스)을 했을 때 **무엇이 달라야** 공정한가?

**지표 후보** 교전거리·TTK 실측·선제공격 비율·정보획득→교전 지연시간
**변주 축** 구조=엄폐물 밀도/시야선 · 규칙=TTK·감지반경 · 인원=1v1↔NvN

---

## PACK-B · 생존/추격 (Survival / Chase / Horror)
**결정적 디테일**
- **위협의 예측가능성** — 완전 랜덤이면 불공정, 완전 예측이면 지루
- **자원 압박** — 무엇이 부족한가(체력·시간·빛·탄약)
- **안전지대 유무** — 쉴 곳이 있나, 있다면 얼마나
- **정보 비대칭** — 추격자와 도망자가 아는 것의 차이

**필수 질문**
1. 플레이어를 압박하는 것은 무엇이고, **얼마나 빨리** 조여오나?
2. 위협이 다가옴을 **어떻게 알아채나**? (경고 신호가 있나)
3. 안전한 순간이 있나? 그 순간에 무엇을 하나?
4. 도망자와 추격자 중 **누가 더 많이 아는가**?

**지표 후보** 생존시간·안전지대 체류비율·위협 인지→회피 지연·자원 고갈 시점
**변주 축** 구조=탈출로 수/시야차단 · 규칙=위협 속도·자원량 · 인원=추격자 수

---

## PACK-C · 퍼즐/탐색 (Puzzle / Exploration)
**결정적 디테일**
- **해답 공간** — 정답 1개인가, 여러 경로인가
- **힌트 구조** — 막혔을 때 무엇이 길을 알려주나
- **난이도 곡선** — 새 규칙 도입 → 연습 → 응용 → 변주의 리듬
- **아하 순간** — 무엇을 깨닫는 순간이 쾌감인가

**필수 질문**
1. 플레이어가 **깨달아야 하는 것**은 정확히 무엇인가?
2. 막혔을 때 **다음에 시도할 것**이 명확한가? (아니면 무작위 시도로 전락)
3. 한 번 푼 퍼즐을 다시 하면 재미있나? (아니면 1회성)
4. 새 규칙을 **몇 번 연습**시킨 뒤 응용을 요구하나?

**지표 후보** 해결 시간·시도 횟수·힌트 도달률·재시도 후 개선율
**변주 축** 구조=공간 복잡도 · 규칙=힌트량·제한시간 · 인원=협동 퍼즐

---

## PACK-D · 경쟁/대전 (Competitive / Arena)
**결정적 디테일**
- **역전 가능성** — 뒤처진 쪽이 따라잡을 수 있나 (없으면 이탈)
- **지배 전략** — 한 가지만 반복해서 이기는 길이 있나 (재미 사망)
- **스킬 표현 폭** — 잘하는 사람이 잘하는 티가 나나
- **매치 길이** — 한 판이 얼마나 걸리고 왜 그 길이인가

**필수 질문**
1. 5:0으로 지고 있을 때 **따라잡을 수단**이 있나?
2. 가장 강한 전략은 무엇이고, 그것의 **약점**은 무엇인가?
3. 실력 차이가 **어떤 지표**로 드러나나?
4. 한 판의 길이는? 진 사람이 **바로 다시** 하고 싶어지는 길이인가?

**지표 후보** 승률 분포·역전 발생률·행동 다양성 지수·매치 길이 분산
**변주 축** 구조=맵 대칭성 · 규칙=역전 메커니즘·페널티 · 인원=팀 규모

---

## PACK-E · 협동 (Co-op / Social)
**결정적 디테일**
- **상호의존** — 혼자 다 할 수 있으면 협동이 아니다
- **역할 분화** — 각자 다른 일을 하나, 같은 일을 여럿이 하나
- **소통 필요도** — 말 없이도 되나, 말해야만 되나
- **무임승차** — 한 명이 놀아도 굴러가나

**필수 질문**
1. **혼자서는 못 하는 것**이 무엇인가? (없으면 협동 설계 실패)
2. 각 플레이어가 하는 일이 **어떻게 다른가**?
3. 서로에게 **무엇을 알려줘야** 하나?
4. 한 명이 실수하면 팀 전체가 어떻게 되나? (과하면 비난, 없으면 무의미)

**지표 후보** 상호작용 빈도·역할별 행동 분포·동시 행동 비율·무임승차 감지
**변주 축** 구조=분리된 공간 · 규칙=의존 강도 · 인원=2인↔4인(핵심 축)

---

## PACK-F · 파쿠르/이동 (Movement / Parkour / Racing)
**결정적 디테일**
- **이동의 손맛** — 조작 자체가 재미인가
- **최적 경로** — 숨은 지름길이 있나, 발견 가능한가
- **실수 비용** — 떨어지면 얼마나 되돌아가나
- **속도 vs 정확** 긴장

**필수 질문**
1. 이동 조작 **그 자체가** 기분 좋은가? 무엇이 그렇게 만드나?
2. 같은 구간을 **더 잘 갈 방법**이 있나? 어떻게 발견하나?
3. 실패하면 얼마나 잃나? (체크포인트 밀도)
4. 빨리 가려면 무엇을 **포기**해야 하나?

**지표 후보** 구간 기록·경로 다양성·실패 지점 분포·회차별 기록 개선율
**변주 축** 구조=코스 복잡도/분기 · 규칙=속도·중력·체크포인트 · 인원=경쟁 주자 수

---

## PACK-G · 건설/자원 (Building / Economy)
**결정적 디테일**
- **자원 흐름** — 무엇이 들어와서 무엇으로 나가나
- **선택의 되돌림** — 잘못 지으면 복구 가능한가
- **성장 곡선** — 초반/후반 속도 차이
- **표현 vs 최적화** — 예쁘게 짓는 재미인가, 효율의 재미인가

**필수 질문**
1. 플레이어가 관리하는 **희소 자원**은? 그게 부족해서 생기는 선택은?
2. 지은 것을 **되돌릴 수 있나**? 비용은?
3. 30분 뒤와 3시간 뒤의 플레이가 **어떻게 다른가**?
4. 최적해가 하나면 표현의 여지가 없다 — **다양한 정답**이 있나?

**지표 후보** 자원 병목 시점·건설 다양성·되돌림 빈도·성장 속도 곡선
**변주 축** 구조=부지 제약 · 규칙=자원 산출률·비용 · 인원=공유 자원 경쟁

---

## 하이브리드 처리
- 두 팩이 걸치면 **둘 다의 필수 질문**을 던지되, **어느 쪽이 주(主)인지** 먼저 확정한다.
- 주 팩의 지표를 **판정 기준**으로, 부 팩의 지표는 **보조 관측**으로 둔다.

## 팩 추가 규칙
새 장르를 만나면: 결정적 디테일 3~5개 · 필수 질문 4개 · 지표 후보 · 변주 축 3종(구조/규칙/인원)을
같은 형식으로 추가한다. **관습적 수치는 넣지 않는다**(예시로만, 사용자 확정 필요).
