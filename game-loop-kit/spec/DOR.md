# DOR — Definition of Ready (기획서 승인 게이트)

> **왜:** 기획이 덜 된 채 레벨을 만들면 3시간을 태우고도 **판단 불가**한 결과가 나온다.
> 이 체크를 통과해야 레벨 작업(티켓)을 시작한다. 통과 못 하면 **INTAKE로 되돌아간다.**

## 통과 조건 (전부 ✅ 여야 착수)

### 1. 재미가 정의됨
- [ ] `FUN-DEPTH.md` D-NN: **4층 중 3층 이상** 채움 (표층만이면 반려)
- [ ] **긴장 대립쌍** 1개 이상 + 가장 팽팽해지는 조건
- [ ] **실패 모드 3개 이상** + 각각의 반증 지표

### 2. 판단 가능함 ⭐ (적대적 리뷰 B-0과 동일 기준)
- [ ] `FUN-HYPOTHESIS.md` H-NN: 가설이 **한 문장**으로 서술됨
- [ ] **자동 지표** 정의 — 각 지표가 *어떻게 로그로 수집되는지* 명시
- [ ] **구별성**: 재미있는 플레이 vs 없는 플레이가 **다른 값**을 낼 것이라 설명 가능
- [ ] **반증 조건**: "어떤 결과면 이 가설을 버린다"가 적혀 있음
- [ ] **판정식** (지지/기각/애매) + 임계값 또는 "대조군 후 확정" 명시

### 3. 실험이 설계됨
- [ ] 겨냥하는 **층** 1개 명시 (가장 불확실한 층)
- [ ] **4레벨 변주** 조건표 (A 대조 / B 구조 / C 규칙 / D 인원) — 각 **한 축만** 변경
- [ ] 표본 수 N과 실행 조건(시드·길이) 정의

### 4. 만들 수 있음 (UEFN에서)
- [ ] **네이티브 지수 통과**(`UEFN-DESIGN-SPACE.md` §4): 형태가 §2 표 안 · 비틀기 1개가 §1 시스템으로 구현됨 · 코어 메카닉의 스톡 디바이스(+Verse 배선) 비율 ≥ 70% · 카메라/물리/렌더 개조 0 · "왜 UEFN인가" 한 줄. GDD §0에 기록됨
- [ ] **`UEFN-FEASIBILITY.md` 판정 완료** — 코어 메카닉에 🔴 RED 없음(있으면 대체 설계로 교체됨)
- [ ] 🟡 AMBER 항목의 **대체 설계가 확정**돼 티켓에 명시됨
- [ ] 불확실한 항목은 **30분 스파이크**로 확인했거나 그 티켓이 먼저 잡혀 있음
- [ ] `assets.md`에 필요한 디바이스·에셋 refPath 존재 (없으면 조사 티켓 먼저)
- [ ] **자동 구동 모드** 계획 있음 (없으면 A레벨에 구축 티켓 필수)
- [ ] **GUI 전용 단계** 식별됨(`capabilities` 확인 근거 첨부) → 별도 티켓 + `deferred`. @editable 배선·설정값은 오프라인 가능(`bind_editable`)이므로 GUI 사유가 아니다
- [ ] 장르 팩(`GENRE-PACKS.md`) 필수 질문 4개 답변됨
- [ ] **`spec/MAP.md` 작성됨**(구역 5종·동선·구조·시야·구조 축 변수) · **플로우 검증 F1~F10 fail 0**(`loop/verify/flow.md` ①). 규칙 없는 구역·자리 없는 규칙·결정 없는 연속 구간이 남아 있으면 반려
- [ ] **비주얼 자산 경로 확정**(`loop/visual-options.md`): 기본은 T0·T1·1c. 블렌더·Fab·AI 생성(T3~T5)을 쓸지 **사용자에게 묻는다**(루프 착수 후에는 못 묻는다).
- [ ] T4(블렌더)를 쓰기로 했으면 **전제조건을 실행으로 확인**: `mcp__blender-assets__get_scene_info`(블렌더 실행·MCP :9876 연결) · `get_polyhaven_status` · `get_sketchfab_status`(API 키) · `get_hyper3d_status`/`get_hunyuan3d_status`(생성 쓸 때). 하나라도 실패면 T4는 이번 세트에서 제외하고 자산 티켓(ASSET-NN)으로 미룬다.
- [ ] **구조 설명서 형식 합의**: `build.md` 구조 절(테마·구역표·동선·스크린샷 3장)을 레벨마다 쓰기로 함. 사용자가 원하는 추가 항목이 있으면 지금 받는다.

### 5. 시간이 잡힘
- [ ] `TIMEBOX.md` 배분 확인 · 레벨당 3시간(A레벨 4시간) 수용 가능
- [ ] 3시간 초과 위험 지점 1~2개 사전 식별

## 게이트 절차
1. 위 체크 자체 점검
2. **적대적 리뷰 전면 공격(B-0 판단가능성 우선)** 1회 — `loop/review/ADVERSARIAL.md`
3. Blocker 0 → **착수 승인**. Blocker 있으면 해당 spec 수정 후 재게이트.

> ⚠️ **가장 흔한 반려 사유:** 2번(판단 가능함). 재미는 정의했는데 **그걸 관측할 방법**이 없거나,
> 지표가 재미있는/없는 플레이를 **구별 못 한다**. 여기서 막히면 만들지 말고 지표부터 고친다.
