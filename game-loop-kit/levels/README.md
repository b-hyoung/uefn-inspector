# levels/ — 변주 레벨별 산출물·측정

한 변주 = 한 폴더(`LEVEL-A`, `LEVEL-B`…). 같은 재미 가설을 **다른 조건**으로 시험한다.

```
LEVEL-A/
  build.md      이 레벨의 구성(공간·규칙 설정값) + 빌드 상태
  autoplay.md   자동 실행 기록(사람 없음)
  metrics.md    자동 지표 수집 결과(Verse 로그 파싱)
```
> 레벨 자체(.umap/디바이스)는 UEFN 프로젝트에 있고, 여기엔 **정의·결과**만 둔다.
> 구조 검증은 uefn-inspector로(`loop/verify/structural.md`).
