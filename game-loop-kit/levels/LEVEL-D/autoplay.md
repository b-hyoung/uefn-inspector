# LEVEL-D — 자동 실행 기록 (사람 없음)

루프가 PIE를 자동 실행해 지표를 수집한 기록. 사람 소감은 수집하지 않는다.

## 실행 설정
- 실행 방식: \<봇/시뮬레이션 스위치 (예: Verse의 SoloTest/AutoPlay 모드)\>
- 실행 횟수: \<N\>회 · 회당 길이: \<초\>
- 조건 고정: \<시드·시작위치·난수 통제 방법\>
