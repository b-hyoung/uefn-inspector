## ★ 1. UEFN MCP 도구가 세션에서 사라짐 → **raw HTTP 직접 연결**
- **막힌 것:** 세션 시작 시 `unreal` MCP 서버가 잠깐 끊기자 `mcp__unreal__*` 도구가 도구 목록에서 영구히 사라짐. `claude mcp list`는 "Connected"로 표시되는데 호출 불가. 브리지(`unrealclaude`)도 "에디터 미실행" 오응답.
- **우회:** 포트 8000에 **MCP 프로토콜 핸드셰이크를 직접** 수행.
  `initialize` → `Mcp-Session-Id` 헤더 획득 → `notifications/initialized` → `tools/call`
- **산출물:** `도구(우회산물)/uecall.ps1` — 이후 **모든 자동화의 기반**이 됨
- **효과:** Verse 작성·컴파일, 디바이스 배치, 세션 실행, 로그 수집 전부 가능해짐

## 2. Epic 계정 인증 만료로 플레이 세션 불가 → 재로그인
- **막힌 것:** `StartSession`이 콘텐츠 업로드까지는 가는데 게임 클라이언트가 접속 못 하고 서버가 닫힘.
  `ossv2_auth_token_refresh_failed: EOS_NotFound`, `FindSingleSession 404`
- **우회:** UEFN 재로그인 → 정상화. 단 **1~2시간마다 재발**(자동 로그아웃)하므로 장시간 작업 시 주기적 재로그인 필요.

## 3. 서버 Verse `Print`가 클라이언트 로그에 없음 → 에디터 로그 직접 grep
- **막힌 것:** `GetClientLogEntries`가 계속 "No client log was found" 반환
- **원인:** `creative_device`의 `Print`는 **서버측** 실행 → **에디터 로그**에 남음. 그 툴은 클라 로그를 읽음.
- **우회:** `%LOCALAPPDATA%\UnrealEditorFortnite\Saved\Logs\UnrealEditorFortnite.log`를 `LogVerse: : [M]` 패턴으로 grep

## 4. `find_actors`가 에디터를 30분 프리즈 → refPath 원장 + 오프라인 검증
- **막힌 것:** 씬 전체(50만 오브젝트) 스캔으로 에디터 완전 정지. MCP 전체 무응답.
- **우회:** ① 배치할 때 반환된 refPath를 **즉시 JSON 원장에 기록**(`state/arenaV2_*.json`)
  ② 전수 조사는 **uefn-inspector 오프라인**으로 (에디터 부하 0)
- **산출물:** `도구(우회산물)/verify_arenas.py`

## 5. 배치한 액터가 오프라인 도구에 안 보임 → `save_actor` 필수
- **원인:** OFPA(액터당 파일 1개) 구조라 배치 직후엔 메모리에만 존재
- **우회:** 배치 후 각 액터에 `save_actor` 호출 → 디스크 기록 → 오프라인 분석 가능
- 실측: 저장 전 23액터 → 저장 후 76액터

## 6. 텔레포터 디바이스 연결 불가 → **Verse 좌표 기반 포털**
- **막힌 것:** 빌트인 텔레포터의 그룹 연결이 GUI 전용
- **우회:** Verse가 0.35초마다 플레이어 위치를 검사해, 포털 좌표 반경 350 안에 들어오면 다음 아레나로 `TeleportTo`. **GUI 배선 완전 불필요.**
- **산출물:** `shadow_bait_hub.verse` (컴파일 clean) + 포털 시각화(비계 게이트·흰 조명·글로우스틱)

## 7. 스폰 위치가 랜덤 → A 아레나 단일화
- **막힌 것:** 스폰패드를 4개 아레나에 다 놔서 어디서 시작할지 불확실 + 원점 기본 PlayerStart(허허벌판) 위험
- **우회:** B/C/D 스폰패드 제거 → 항상 A에서 시작 → 포털로 순환

## 8. 프롭 배치가 조용히 실패 → 액터 이름에 인덱스 부여
- **원인:** `add_to_scene_from_asset`의 `name`이 중복되면 에러 없이 실패 (20개 중 4개만 성공)

## 10. 에셋 전체 검색 시 엔진 플러그인 에러 → 폴더 지정 검색
- `find_assets` 전체 스캔 → `AmbientAudio.uplugin` 경로 에러
- **우회:** `folder_path`로 좁혀서 검색. `/Game/Playgrounds/Items/Props`(127개)에서 콘서트 프롭 발굴

## 11. PowerShell `switch` 반환이 배열 → 강제 스칼라화
- **증상:** `$H*2`가 "op_Multiply 없음" 에러. **문자열 보간에선 정상처럼 보여** 디버깅 난이도 높음
- **우회:** `$H = [int](@($spec.half)[0])`

## 12. PowerShell 함수의 미포획 출력이 반환값에 섞임 → 정규식 파싱 분리
- **증상:** refPath 대신 배열이 반환돼 "경로 공란"으로 배치 실패
- **우회:** `return` 명시 + `RefOf()` 정규식 헬퍼로 파싱

## 13. 한글 주석 .ps1이 파서 에러 → 영문 주석
- BOM 없는 UTF-8 파일을 PS 5.1이 ANSI로 읽어 깨짐 → 구문 오류
- **우회:** 스크립트는 영문 주석, 또는 인라인 실행

## 14. Verse 컴파일 함정 6종 → 각각 회피
| 함정 | 회피 |
|---|---|
| `int / int` = **rational**(정수 아님) | 제곱거리 비교로 나눗셈 제거 |
| `if (c) then A else B` — **then 필수** | 키워드 추가 |
| if 조건에서 호출하는 순수함수는 `<computes>` 필요 | 단, **객체 생성 함수는 `<computes>` 불가** |
| 비교(`<=`,`and`)를 `loop` 본문에 직접 못 씀 | `if` 조건으로 이동 |
| `Err`, `TICK` 등 이름 충돌 | `HUB_TICK` 등으로 개명 |
| `vector3`는 `/UnrealEngine.com/Temporary/SpatialMath` | `/Verse.org/SpatialMath` 아님 |
