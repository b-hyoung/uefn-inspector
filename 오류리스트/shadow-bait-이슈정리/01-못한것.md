# 끝내 못한 것 (블로커)

---

## 🔴 1. `@editable` 배선 자동화 — **최우선, 게임을 막고 있음**

**하려던 것:** Verse 게임 디바이스에 가드 스포너·오디오 플레이어를 연결해서, 미끼로 가드를 유인하고 배후 역습을 구현.

**왜 중요한가:** 이게 이 게임의 **코어 재미**(예측 지배감 = 내가 유도한 대로 술래가 움직임). 없으면 그냥 "코인 줍는 스텔스"입니다.

### 시도한 4가지 경로 (전부 실패)

| 경로 | 결과 |
|---|---|
| `DeviceToolset.SetDeviceProperty` (Verse 디바이스) | 프로퍼티 **노출은 성공**(`guardSpawner`,`decoyAudio`가 보임). 값 설정 시 **"is not valid guard_spawner_device"** — 배치된 블루프린트 액터를 Verse 클래스 타입으로 거부 |
| 서브오브젝트 경로 추측 3종 (`.guard_spawner_device_0` 등) | 전부 실패 — 그런 export 자체가 없음 |
| uefn-inspector `write.set_object_ref` | 불가 — `SavedActor` 프로퍼티가 **없고**, import 테이블에 대상 액터도 **없음**. 둘 다 신규 추가 = 파일 크기 변경 → `rebuild.py` fixup 엔진 미완성 |
| uefn-inspector `add_binding` | 용도 불일치 — 슬롯 export **복제**용이지 배선 **값 주입**용이 아님 |

### 파일 구조 실측 근거
```
__verse_0x04365773_GuardSpawner  →  { 이벤트 서브객체 11개만, SavedActor 없음 }
게임 디바이스 import 60개          →  가드 액터 인스턴스 없음
가드 액터 파일 (export 50/import 86) →  Verse 래퍼 객체 없음
```
→ Verse 래퍼는 **에디터가 배선하는 시점에 생성**되는 구조. 파일만 고쳐서는 만들 수 없음.

### ✅ 알아낸 것 (절반은 자동화 됨)
`@editable` **슬롯 자체는 자동 생성 가능**했습니다 — Verse에 선언 → 컴파일 → `save_actor` 하면 슬롯 export/import가 파일에 생깁니다. **비어 있는 값만** 못 채웁니다.

### 필요한 조치 (사용자, 30초)
UEFN에서 `VerseDevice`(위치 `0, 26500`) 선택 → 디테일 패널의 `Guard Spawner`·`Decoy Audio` 슬롯에
B 아레나 가드(`2200, 32200`)·오디오(`2000, 27800`) 지정 → Ctrl+S.
**1회만 하면 됨.** 이후 다른 대상으로 *변경*은 `set_object_ref`로 오프라인 자동화 가능(동일 크기라 검증된 기능).

## 🔴 2. 무기 지급 / 클래스 선택
아이템 그랜터 디바이스의 **무기 설정이 GUI 전용**. 1번과 같은 뿌리(디바이스 참조·설정).
현재 플레이어는 기본 곡괭이만 소지. "상호 한 방" 전투 미구현.

## 🔴 3. 오디오 사운드 지정
미끼용 `audio_player_device`는 배치·배선됐지만 **어떤 소리가 나는지 미확인**(기본값). 사운드 선택이 GUI.

## 🔴 4. 텔레포터 디바이스 그룹 연결
빌트인 텔레포터의 그룹 연결은 GUI 전용. `SetDeviceProperty`는 빌트인에 **아예 불가**("not valid ScriptDevice").
→ **Verse 좌표 기반 포털로 우회 성공** (02번 문서 참조)

## 🟡 5. 가드가 미끼 소리에 반응하는가 — 미검증
오디오 재생은 확실하지만 **가드 AI가 소리를 듣고 이동하는지 확인 못 함**.
1번 배선이 되면 Verse로 직접 가드를 유인하므로 이 의존 자체가 사라짐.

## 🟡 6. `engine_devices` 카탈로그 없음
uefn-inspector의 디바이스 검색 기능(1119개). Fortnite 설치본 파생물이라 저장소에 없음, 직접 생성 필요.
→ **라이브 MCP `ListDeviceAssets`로 우회 성공**

## ⚪ 7. 봇 자동측정 시뮬레이션 — 폐기
술래·수비 봇을 시뮬레이션해 재미 지표를 자동 수집하려 했으나, **지표가 전부 0**으로 나옴
(봇 술래가 랜덤 순찰이라 조우 자체가 발생 안 함). 사용자 지시로 직접 플레이 테스트로 전환.
파이프라인(빌드→세션→로그 수집)은 정상 작동 확인됨.
