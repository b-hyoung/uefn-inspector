## 🟡 C. 시도했으나 막힌 것 (기록)

### C-1. @editable 배선 자동화 — 4가지 경로 전부 실패
| 시도 | 결과 |
|---|---|
| `DeviceToolset.SetDeviceProperty` (액터 refPath) | ❌ "is not valid guard_spawner_device" — 타입 검증 거부 |
| 같은 툴 (서브오브젝트 `.guard_spawner_device_0` 등 3종 추측) | ❌ 전부 실패 |
| uefn-inspector `set_object_ref` | ❌ 대상이 import 테이블에 없음 + `SavedActor` 프로퍼티 자체가 없음 → **둘 다 신규 추가 = 크기 변경**, fixup 엔진 미구현 |
| uefn-inspector `add_binding` | ❌ 용도가 다름 — "슬롯 export 복제"이지 "배선 값 채우기"가 아님 |

**실측 근거:**
- 슬롯 export·import는 이미 존재 (`__verse_0x04365773_GuardSpawner`, cls=`guard_spawner_device`)
- 그러나 그 export의 프로퍼티에 **`SavedActor` 없음** (이벤트 서브객체 11개만)
- 게임 디바이스 import 60개에 **가드 액터 인스턴스 없음**
- 가드 액터 파일(exports 50, imports 86)에 **Verse 래퍼 객체 없음** → 에디터 배선 시 생성되는 구조

→ uefn-inspector 능력표의 "새 @editable 슬롯 배선 = ⚫ HUMAN(GUI)"와 일치. 문서가 맞았음.

### C-2. 미검증 항목
- **가드가 미끼 소리에 반응하는가** — 오디오 재생은 확실. 가드 AI의 소리 반응은 미확인.
  배선 후 Verse로 직접 유인하면 이 의존이 사라짐(B-1이 해결).
